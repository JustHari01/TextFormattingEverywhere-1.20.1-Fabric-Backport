# Text Formatting Everywhere (UNOFFICIAL)

Unofficial Fabric backport of [Text Formatting Everywhere](https://www.curseforge.com/minecraft/mc-mods/text-formatting-everywhere) for Minecraft 1.20.1.

The mod restores typing the section sign (`§`) in supported text fields so Minecraft formatting codes can be used in chat, anvils, signs, and books. On servers, the server must allow the character for chat formatting to work. Sign text is kept intact when the server processes the update.

## Compatibility

- Minecraft 1.20.1
- Fabric Loader 0.14.0 or newer
- Java 17 or newer
- Client-side and server-side
